3D Prototype for Visualizing Urban Thermal Stress

An interactive visualization prototype that maps urban thermal stress across a residential neighborhood in Seestadt, Vienna. The main goal of this project is to design and evaluate a prototype that eases the exploration and interpretation of thermal stress distributions for the general public.

The prototype was developed using Unity, with the C# visual analytics pipeline. It provides an interactive 3D environment in which users can explore Universal Thermal Climate Index (UTCI) data through navigation, interface controls, and visual encodings.

Visual Encodings

  • Point clouds: Discrete 3D spheres positioned at exact simulation coordinates.
  • Horizontal planes: Continuous surfaces stacked from 0 to 10 meters at 2-meter vertical intervals.

Interface Controls

An hourly time slider (1–24h), scenario toggles for Tree Condition and Warm/Cold Condition, and two independent opacity sliders to adjust the opacity of the UTCI visualization and the 3D building models separately.

Activity Mode

Translates thermal stress data into relatable everyday activities. When an Activity Mode is enabled, the visual output dynamically filters the active dataset to show only relevant areas:

  • Walk the Dog: Isolates ground-level thermal safety areas for dogs.
  • Sunbathing / Winter Walk: Isolates comfortable areas for solar exposure.
